# savefile

一个只依赖 Python 标准库的存档序列化与版本迁移内核：把内存里的一份存档 map
写成带校验的二进制 blob，读回时先校验容器、再把记录沿版本链迁移到当前版本。
它不读写文件、不监听端口，只在内存里对 bytes 做编解码。

- 容器：4 字节标识 + 1 字节版本 + 记录 + 4 字节 CRC32 校验
- 记录：带标签的值编码，整数走 zigzag varint，文本带字节长度，
  列表带条目数，map 带键值对数并按 key 升序写出
- 版本：每个版本声明自己带的字段；旧版本记录经单步迁移链改名、丢弃、填默认
- 错误情形：标识或版本不认识、校验和不对、正文截断、正文后有多余字节、
  键序不规范、文本不是合法 UTF-8、字段缺失或类型不符

## 目录

- savefile/core.py：二进制读写、校验与版本迁移
- tests/test_core.py：行为测试

## 跑测试

在项目根目录执行：

    python3 -m unittest discover -s tests -v
